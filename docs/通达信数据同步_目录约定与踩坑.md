## 三、日终同步流程

1. 通达信客户端 **盘后数据下载**（vipdoc 落分钟线；`TimeDown=0` 时需手动，见第四节）
2. `python tools\tdx_min_to_quantdb.py --kind min`
3. `python tools\tdx_exday_daily.py`
4. `python tools\verify_sync.py`

## 六、已知坑

1. **vipdoc 曾被清空**（2026-11-20 检查时仅剩 cw\ 财务 dat），历史分钟/日线需靠盘后下载逐日重建；1 分钟历史深度约 100 自然日、5 分钟约 5-6 年（见记忆卡《通达信下载额度实测》）。

3. `git.exe` / `netstat.exe` / `python.exe` 等子进程在只读沙箱下报 `\\.\pipe\LOCAL\dotnet_*` 拒绝：属沙箱边界，需 `danger-full-access` 一次性提权重试同一命令。
4. 控制台输出避免 emoji（Windows GBK 控制台 `UnicodeEncodeError`），用 `[OK]/[MISS]` 文本标记，或在脚本入口 `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`。
